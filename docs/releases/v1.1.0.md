# Xerver v1.1.0

Windows x64 正式版，构建日期 2026-08-31。强烈建议更新。

## 更新内容

- **修复托盘右键菜单**：改用支持 Unicode 的菜单绘制方式，修复部分 Windows 环境中文显示为方框或乱码的问题；保留打开和退出功能。
- **更改后端打包方式**：后端及 Python、Qt 运行库完整随安装包部署，启动时直接从安装目录加载，减少临时解压导致的启动失败和被安全软件拦截的可能。
- **降低杀毒软件误报可能性**：关闭 UPX，避免后端运行时重复释放临时文件；增加完整性校验和启动诊断日志。此项只能降低误报可能性，不能替代代码签名或保证所有安全软件都放行。
- **优化开机启动行为**：只在用户实际切换开机自启动时更新启动项；新增“开机最小化到托盘”，启动后可直接从托盘打开主界面。
- **完善错误日志**：记录前后端启动阶段、运行库路径、进程退出和本地 API 就绪状态，方便定位卡在初始界面的问题。

安装包尚未做代码签名。如果安全软件仍提示，请保留报警时间和对应的 `frontend.log`、`backend.log`，不要上传 `config.json`、密码或私钥。安装前请完全退出旧版 Xerver（包括托盘进程）。

SHA-256 校验文件随安装包一起提供。
