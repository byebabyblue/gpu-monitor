# Xerver v1.0.2-test.1

Windows x64 预发布测试版，构建日期 2026-08-31。本版不替换 v1.0.1 正式版。

下载 `Xerver-1.0.2-test.1.exe` 即可安装，大小为 155,341,824 字节（148.15 MiB）。安装包包含完整前端、Java 运行环境、Python 后端及依赖，不需要另装 Java 或 Python。

## 本次调整

- **后端完整目录打包**：运行库随安装包一起安装，直接从 `_internal` 加载，不再每次启动都解压到新的临时目录；UPX 仍保持关闭。
- **避免重复写入自启动项**：仅在用户实际切换“开机自启动”时更新 Xerver 的启动项；启动程序、保存壁纸等无关设置不再重复写入。安装版优先直接启动 `Xerver.exe`。
- **托盘中文缺字修复**：菜单改用 Swing 绘制，使用与系统语言无关的字体名称匹配，并检查实际中文字形支持；没有可用中文字体时回退为可读英文。保留托盘打开、退出功能。
- **打包完整性检查**：校验整个后端目录、Python/Qt 必需组件和逐文件 SHA-256，文件缺失、损坏或混入额外文件时停止打包。
- **启动诊断**：保留前后端错误日志，新增运行库位置及 Qt/API 初始化阶段记录。

## 验证结果与范围

- 29 项 Python 自动化测试、35 项前端自动化测试全部通过。
- 从最终 EXE 安装包提取实际安装文件后进行启动测试；完整镜像共 551 个文件。
- 后端清单覆盖 353 个文件，共 144,736,713 字节，逐文件校验通过。后端 EXE 约 6.49 MiB，其余依赖位于 `_internal`，不能只看 EXE 大小判断是否缺包。
- 自启动设置为关、开的两个隔离配置均成功进入主界面、连接本地 API 并保存普通设置，随后分别连续检查 15 秒；两轮测试前后启动项保持不变，后端文件完整。
- 打包的 Java 环境选用 Microsoft YaHei UI，中文字符检查通过；托盘组件的显示/关闭、菜单动作及渲染预览已验证。

上述测试使用空服务器配置，不包含真实 SSH 连接、重启 Windows 后的自启动、安装器覆盖升级或真实任务栏右键的端到端验证。托盘实际显示仍请在安装后确认。

## 安全与试用说明

安装包尚未做代码签名。本次短时测试未观察到后端被终止或删除，但这不是杀毒认证，也不能保证以后不会报警；已有行为检测报告不足以确定具体触发规则。无需关闭杀毒软件或添加白名单。

先完全退出旧版 Xerver（包括托盘进程），再安装测试包。设置页应显示 `1.0.2-test.1`；Windows 安装器内部数字版本为 `1.0.2`。这是预发布版本，不作为正式版自动更新的最新版本。

如果仍卡住或报警，请保留发生时间及安全软件报告。设置中的“打开日志文件夹”可以找到 `frontend.log`、`backend.log`，默认位置为 `%APPDATA%\Xerver\logs`；自定义配置的日志在配置旁的 `logs` 目录。提供日志前请检查并脱敏服务器地址、用户名、文件路径和命令输出，不要上传 `config.json`、密码或私钥。
