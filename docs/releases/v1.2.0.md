# Xerver 1.2.0

- Node 新增服务器侧网络检测：百度、GitHub、清华 PyPI 国内源、PyTorch 官方源。
  分别显示 ICMP ping 和 HTTPS 状态与耗时；每分钟后台检测，不阻塞 GPU 采集。
  未安装 ping/curl、ICMP 被禁、HTTP 错误和连接失败分开显示。
- 修复历史曲线每次刷新重新抽点造成过去曲线变形的问题。使用固定时间桶，
  并保留样本计数，避免重复压缩改变历史平均值。支持暂停/继续两张曲线。
- GPU 显存信息提升至设备卡片主视觉，显示用量、总量、剩余 GiB、占比和进度条；
  90% 及以上用红色提示。新增与利用率相同时间范围的显存占比曲线。
- 调整玻璃材质：柔和折射、顶部高光、随文字模式变化的可读性底色，参考 iOS 控制中心。
- 修复切换壁纸残留上一张画面、缓存损坏无法重建、缓存尺寸报告不准确的问题。

- 修复 GPU 查询失败时清空历史，以及设备暂时缺失/顺序变化时历史对应错误。
- 网络使用独立 SSH 连接，复用已确认指纹；空闲轮询不影响每分钟检测。
- 本地 API 拒绝网页 Origin 和非回环 Host，并要求 JSON 请求格式。
- SSH 认证/握手失败时显式关闭临时连接。

历史保留于内存，后端重启后重新采集；最近一小时保留原始样本，1–6 小时使用
30 秒加权桶，6–24 小时使用 120 秒加权桶，兼容各时间范围的图表精度。
HTTPS 请求耗时包含 DNS/TLS，不代表下载速度；远程工具缺失时不会假报成功。

验证：45 项 Python 测试、37 项 Kotlin 测试通过；四张深浅主题实际组件离屏预览
已检查。Windows 原生应用及从最终 EXE 提取的应用均通过启动烟测，确认内置
Python/Qt 运行库、中文托盘菜单、本地 API 就绪，且开机启动项未被改写。
开启/关闭开机启动偏好两种配置均已测试。

Astra 已独立审查代码并复查修复，额外验证历史跨层稳定性、双主机密钥协商及
SSH 失败连接清理。旧远程 SSH 测试入口拒绝连接，未完成真实 GPU 服务器网络烟测；
网络命令、失败状态及独立连接路径已通过模拟和本地集成测试。界面预览使用模拟数据。

Windows x64 安装包与 SHA-256 校验文件随本版本发布。安装前请退出旧版 Xerver，
包括托盘中的进程。本版本没有代码签名。
